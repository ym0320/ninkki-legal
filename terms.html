利用規約

最終更新日: 2026年4月6日

第1条（適用）

本利用規約（以下「本規約」）は、SNSシミュレーション体験アプリ「Ninkki」（以下「本アプリ」）の運営者（以下「運営者」）が提供するすべてのサービスの利用条件を定めるものです。ユーザーは本アプリを利用することにより、本規約のすべての条項に同意したものとみなされます。

第2条（サービスの概要）

  1. 本アプリは、SNSの体験をシミュレーションとして楽しむことを目的としたアプリケーションです。
  2. 本アプリ内に表示されるフォロワー、コメント、リアクション等はすべてAI(人工知能)により自動生成されたものであり、実在する人物によるものではありません。
  3. 本アプリ内に表示されるフォロワー数、いいね数、共有数等の数値はすべてシミュレーションであり、実際のSNSにおける数値ではありません。
  4. 本アプリは実際のSNSサービスではなく、他のユーザーとのソーシャルネットワーキングを主目的とするものではありません。

第3条(アカウント)

  1. 本アプリの利用にあたり、ユーザーはApple、Google、メールアドレスとパスワード、またはゲストログインのいずれかの方法でアカウントを作成できます。
  2. ゲストアカウントで利用する場合、アプリの削除や端末変更時にデータの引き継ぎはできません。ゲストユーザーは設定画面からいつでも正式なアカウントにアップグレードできます。
  3. パスワードを忘れた場合は、メールによるパスワードリセットが可能です。
  4. アカウントの第三者への譲渡、貸与、売買その他の処分は禁止します。
  5. アカウントの管理責任はユーザー自身にあります。
  6. 13歳未満の方は本アプリを利用することができません。13歳未満の方がアカウントを作成した場合、運営者は当該アカウントを事前の通知なく削除できるものとします。

第4条(サービス内容)

  1. 本アプリは、AI(Google Gemini)を活用し、ユーザーの投稿に対するコメント・リアクションを自動生成します。
  2. フォロワー数に応じたエンゲージメント率モデルにより、リアクションの量や頻度が変動します。
  3. 投稿可能な回数および利用可能な機能は、ユーザーが加入しているプランに応じて制限されます。
  4. 本アプリは投稿内容に対してNGワードフィルタリングを実施しており、不適切な表現を含む投稿は制限される場合があります。

第5条(有料プランおよび決済)

  1. 本アプリには以下の3つのプランがあります。 
    【一般人プラン】無料
【有名人プラン】月額680円(税込) / 年額5,400円(税込)
【トップスタープラン】月額1,980円(税込) / 年額15,800円(税込)
  2. 年額プランには初回7日間の無料トライアル期間が付きます。無料トライアル期間終了の24時間前までに解約手続きを行わない場合、トライアル終了後に自動的に有料サブスクリプションが開始され、課金が発生します。
  3. すべての決済はAppleのApp内課金(In-App Purchase)を通じて処理されます。
  4. 有料プランは自動更新サブスクリプションです。更新日の24時間前までに解約しない場合、自動的に次の期間の課金が行われます。
  5. サブスクリプションの解約は、iOSの「設定」アプリ → 「Apple ID」 → 「サブスクリプション」から行うことができます。本アプリ内から直接解約することはできません。
  6. 返金についてはAppleの返金ポリシーに従います。運営者が直接返金を行うことはできません。詳細は Apple公式の返金ポリシー をご参照ください。
  7. 端末変更時やアプリの再インストール時は、「購入の復元」機能により、過去に購入したサブスクリプションを復元することができます。
  8. ゲストアカウントでは有料プランの購読はできません。有料プランをご希望の場合は、メールアドレスとパスワード、Apple、Googleのいずれかでアカウント登録を行ってください。
  9. 上位プランから下位プランへダウングレードする場合、上位プランでのみ利用可能な機能(テーマ変更、フォント変更など)の設定はデフォルトに戻ります。投稿やコメントなどのデータは削除されません。
  10. 現在の購読プラン、次回更新日、更新料金などの詳細は、iOSの「設定」 → 「Apple ID」 → 「サブスクリプション」で確認できます。
  11. App内課金時に生成される購入トークン・レシートは、検証目的でのみAppleに送信されます。クレジットカード番号などの決済情報は、当社のサーバーに保存されません。すべての決済処理はAppleが管理します。

ユーザーは以下の行為を行ってはなりません。

  1. 法令または公序良俗に違反する行為
  2. 他のユーザーに対する嫌がらせ、誹謗中傷、脅迫その他の迷惑行為
  3. 本アプリまたはサーバーへの不正アクセス、システムへの攻撃
  4. 本アプリの運営を妨害する行為
  5. 虚偽の情報を流布する行為
  6. 本アプリのコンテンツ(AI生成コンテンツを含む)を無断で複製・転載・二次配布する行為

第7条(コンテンツの権利)

  1. ユーザーが本アプリに投稿したコンテンツ(テキスト、画像等)の著作権は、当該ユーザーに帰属します。
  2. AIにより自動生成されたコメント、リアクションその他のコンテンツの著作権は運営者に帰属します。
  3. ユーザーは運営者に対し、投稿コンテンツをサービスの運営・改善に必要な範囲で利用する非独占的な権利を許諾するものとします。

第8条(フレンド機能および安全機能)

  1. 本アプリにはフレンド機能があり、フレンド申請・承認を通じて他のユーザーと相互に投稿を閲覧できるようになります。
  2. ユーザーは他のユーザーをブロックすることができます。ブロックされたユーザーは、ブロックしたユーザーのコンテンツにアクセスできなくなります。
  3. ユーザーはリアリティ設定をオン・オフで切り替えることができます。オンにすると、AIが生成するコメントに批判的・否定的なフィードバックが含まれ、よりリアルなSNS体験をシミュレーションします。
  4. 本アプリには誕生日機能があります。ユーザーが誕生日を登録すると、AIが誕生日をお祝いするコンテンツを生成します。
  5. 本アプリにはパスコードロック機能があります。有効にすると、アプリの起動時および他のアプリから戻った際にパスコードの入力が求められます。

第9条(アカウントの削除)

  1. ユーザーはいつでも自身のアカウントを削除することができます。
  2. アカウントを削除した場合、投稿、コメント、フレンド関係、プロフィール情報を含むすべてのデータが完全に削除されます。
  3. 一度削除されたアカウントおよびデータの復旧はいかなる場合もできません。削除前に十分ご確認ください。
